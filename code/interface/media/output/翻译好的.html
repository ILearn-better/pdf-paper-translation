单卷积层具有宽度k小于n时无法连接所有输入和输出位置。实现这一点需要k个连续的卷积层，或者在扩散卷积中需要O(logk(n))个卷积层，从而增加了网络中任意两个位置之间最长的路径的长度。卷积层通常比循环层更昂贵，倍数为k。然而，可分离卷积层显著减少了复杂度，为O(k · n · d + n · d2)。即使k=n，可分离卷积层的复杂度仍然等于自注意力和点间前馈层的组合，这是我们模型中采取的方法。
