# Json遍历方法
遍历json的意思是访问json对象或数组中的每一个元素，通常用于获取或修改json数据。在Python中，有几种方法可以遍历json，例如：

- 使用`json`模块将json字符串转换为Python字典或列表，然后使用`for`循环遍历字典的键值对或列表的元素。例如：

```python
import json
json_str = '{"name": "Alice", "age": 20, "hobbies": ["reading", "coding"]}'
json_obj = json.loads(json_str) # 将json字符串转换为Python字典
for key, value in json_obj.items(): # 遍历字典的键值对
    print(key, value)
```

- 使用`jsonpath`模块来提取json数据中符合特定路径表达式的元素，然后使用`for`循环遍历提取出来的元素。例如：

```python
import json
import jsonpath
json_str = '[{"name": "Alice", "age": 20}, {"name": "Bob", "age": 21}]'
json_obj = json.loads(json_str) # 将json字符串转换为Python列表
names = jsonpath.jsonpath(json_obj, '$..name') # 提取列表中所有对象的name属性
for name in names: # 遍历提取出来的name列表
    print(name)
```

- 使用`pandas`模块将json数据转换为DataFrame对象，然后使用`iterrows()`或`itertuples()`方法遍历DataFrame的每一行。例如：

```python
import json
import pandas as pd
json_str = '[{"name": "Alice", "age": 20}, {"name": "Bob", "age": 21}]'
df = pd.read_json(json_str) # 将json字符串转换为DataFrame对象
for index, row in df.iterrows(): # 遍历DataFrame的每一行
    print(index, row['name'], row['age'])
```
